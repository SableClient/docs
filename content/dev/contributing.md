## Translations

Translate the app and the website on
[Weblate](https://translate.ow-ops.eu/projects/sable-next/). Changes sync back to
the repositories, so don't edit the locale files directly.

## Bugs

Found a bug? [Open an issue](https://git.sable.moe/SableClient/sable-next/issues).
For security issues, use the
[security policy](https://git.sable.moe/SableClient/sable-next/src/branch/main/.github/SECURITY.md)
instead.
